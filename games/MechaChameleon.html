Mecha Chameleon

An Unreal Engine 5.6 game running through the Rexcomp runtime, which recompiles the shipped binaries into WebGPU. Its runtime and game image stream from the project's own CDN as they are needed, so the first boot pulls roughly 140 MB and the rest follows as you play.

This one is heavy. It needs Chrome or Edge 137+ with WebGPU, a real GPU, and about 4 GB of memory for the tab — the same order as the Super Mario Maker 2 port, so a small Chromebook will run out of memory before the title screen.
