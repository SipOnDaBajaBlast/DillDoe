This device probably can't run the game

The game is a full emulated console: it wants several gigabytes of memory, a real GPU with WebGL2/WebGPU, and about 3.1 GB of free storage.

Web port of Super Mario Maker 2 (SMM2 Recomp). Needs Chrome or Edge 133+ for 64-bit WebAssembly memory and WebGPU, and about 3.1 GB of free disk: the first start copies the whole game into the browser's private storage, so keep the tab open until the PLAY button appears. Story mode, the editor and local play work; online levels and course upload don't, because they need a socket proxy a static site can't run. Keyboard (arrows/WASD plus J/K/L/I, F1 for the full list) or a gamepad. On a low-end Chromebook or a 4 GB machine the browser usually runs out of memory and shows its own “Aw, Snap!” page instead — it is meant for a desktop or laptop.
