Super Mario Odyssey

Run the browser port with a keyboard or controller.

The first visit downloads about 5.7 GB of game data and stores it in this browser. Keep the tab open and make sure you have at least 7 GB of free space. Later visits reuse the saved files.

Controls

Move Mario
WASD
Move camera
IJKL
Jump (A)
Space or X
Throw Cappy (Y)
V
Shoulder / trigger buttons
QE / 13
Pause / menu
Enter

Controller: left stick moves, right stick controls the camera. Face buttons follow the selected controller layout in the game’s Web Settings menu.

Choose Faster if movement stutters. Changing this setting takes effect when the game starts.
