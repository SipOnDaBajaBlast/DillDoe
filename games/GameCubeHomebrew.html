GameCube homebrew

A real GameCube core (gecko) compiled to WebAssembly, running small homebrew in this tab. Nothing is uploaded and no game data is served from this site.

Retail discs do not work here, and it is not a bug I can fix in the page: this wasm build declares a maximum of 512 MiB of memory, the core copies the whole image in, and every retail GameCube disc is about 1.1–1.4 GB. The boot aborts with an out-of-memory trap before the game starts. Wind Waker was measured on exactly that wall.

  • What runs: homebrew .dol files and very small disc images — Swiss r2073 is the reference payload
  • Speed: the web core interprets, so expect well below native — the Swiss boot disc measures about 14 fps / 23% on a desktop
  • Browser: WebGPU required — Chrome or Edge 113+, or Safari 26+
  • Audio: none; the web build has no sound output yet
  • Privacy: the file is read in this tab and never leaves your machine
