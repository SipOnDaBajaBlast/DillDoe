Persona 4
browser port

PS2 · 2008WebAssemblyWebGPUAutomatic disc loading

The original PlayStation 2 release, recompiled from its own executable into WebAssembly and run by a browser-native PS2 runtime. Emotion Engine code, VU1 microprograms, the Graphics Synthesizer and SPU2 audio all execute locally in this tab — nothing is streamed from a server.

The Persona 4 (USA) disc loads automatically as you play. The browser requests only the parts it needs, so you do not have to download the entire 4.4 GB image before starting. Your memory card stays in this browser.

Default keys — Z Cross · X Circle · A Square · S Triangle · arrow keys D-pad · Enter Start · Backspace Select · Q L1 · W R1 · 1 L2 · 2 R2 · IJKL left stick. Every button can be rebound inside the game page from Menu → Controls…, or from this page's Controls & keys button; bindings are saved in your browser. Gamepads are picked up automatically.
A current Chrome or Edge browser with WebGPU gives the best performance. If the automatic disc stream is unavailable, open the personal import player and select your own disc image.
