The Wind Waker

A browser prototype: a GameCube core runs your own disc image locally. Nothing is uploaded and no game data is served from this site.

  • Your disc: USA release, GZLE01 revision 0, as .iso, .gcm or .rvz
  • Your browser: one with WebGPU — Chrome or Edge 113+, or Safari 26+
  • Expectations: the web core is an interpreter, so the game runs below full speed, and the web build has no audio yet
  • Privacy: the file is read in this tab, mounted in memory, and never leaves your machine
