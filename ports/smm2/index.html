    Controls

    The keyboard plays as a controller. F1 opens this card; Esc or a click outside closes it.

    ↑ ↓ ← → or WASDMove, menus
    K or SpaceB — the bottom face button: jump in play, place in the editor
    LA — right face button: confirm, run / hold
    JY — left face button
    IX — top face button
    Enter+ (start, pause)
    Backspace− (menu)
    Q / EL / R shoulders
    MouseClicking the picture is a touch on the console's screen (Course Maker); the wheel scrolls
    F11Fullscreen (also the button top-right)
    Shift+F9Log panel (same as the Log button)
    GamepadA real controller still works; it takes the slots after the keyboard
