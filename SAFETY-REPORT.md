# Safety checks

Microsoft Defender scanned the downloaded Fortnite 1.8 archive and the extracted PAK data; both scans reported no threats.

Archive size: 7,811,121,055 bytes. MD5: 8b5bfba4cbf1af3af97d8f5eebae35d1, matching Internet Archive metadata.

Only game data was extracted for this browser build. No Fortnite client executable, DLL, installer or anti-cheat is included. The browser uses bundled local Three.js and data assets; it requires no account or external game server.

A clean scan is evidence of the scan result, not a guarantee that every file is harmless. The browser package was also scanned after the HUD update.
